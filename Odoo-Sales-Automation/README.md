# Odoo Sales Process Automation

## The Challenge
The client faced significant bottlenecks in their sales-to-invoice cycle. Sales representatives were manually entering data from physical order forms into Odoo, leading to a 15% error rate and an average processing time of 10 hours per week per agent.

## The Approach
I conducted an **AS-IS/TO-BE analysis** and mapped the optimized workflow using **BPMN 2.0**. Key actions included:
* Automating field mapping between the Sales Module and Invoicing.
* Implementing automated validation rules to flag errors before record creation.
* Redesigning the order-entry dashboard to minimize keystrokes.
  

## The Outcome
* **Efficiency:** Reduced manual data entry time by 60% (from 10 hours to 4 hours/week).
* **Accuracy:** Decreased data entry error rates from 15% to <1%.
* **Scalability:** The new process supported a 20% increase in order volume without requiring additional headcount.
