# User Story: Order Status Filter

**As a** Sales Representative,
**I want to** filter customer orders by status (e.g., 'Draft', 'Confirmed', 'Invoiced'),
**So that** I can prioritize urgent customer requests and manage my daily workflow efficiently.

## Acceptance Criteria
- [ ] User can see a status dropdown menu in the Sales Order list view.
- [ ] Selecting a status automatically filters the displayed list.
- [ ] The filter remains active when navigating between pages.
- [ ] An 'All' option is available to clear the filter.

*Note: This requirement follows the **INVEST** criteria to ensure the story is Independent, Negotiable, Valuable, Estimable, Small, and Testable.*
